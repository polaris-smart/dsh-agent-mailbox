## 2026-09-16 · publish job TS5096 根因修复（`830d4bd`）
**做了什么**（老板经 HS 转来 tag v0.1.0 的 CI 红叉：三平台 test 全绿、publish 9 秒失败）：
- **根因定位（非凭据问题）**：publish job 的 `npx tsc -p tsconfig.build.json` 报
  `TS5096: Option 'allowImportingTsExtensions' can only be used when either 'noEmit' or 'emitDeclarationOnly' is set` 并 exit 2——build 步即死，走不到 `npm publish`，与 NPM_TOKEN 无关
- **连带缺陷（本次新发现）**：即便绕过 exit code 拿到 dist/，emit 的 JS 仍写 `from './mcp-client.ts'`，而 dist/ 下只有 `.js` ⇒ 已上架的 `dsh-agent-mailbox@0.1.0` 对消费者**不可用**（实测 `import 'dsh-agent-mailbox'` = ERR_MODULE_NOT_FOUND；走 `src/*.ts` 亦不可，Node 拒绝 node_modules 下的类型剥离）
- 修复：tsconfig.build.json 开 `rewriteRelativeImportExtensions`（TS≥5.7，emit 时 .ts→.js）；CI 与 smoke 的 TS 5.6.3→5.9.3；publish job 增 dist 入口校验步；PRD 兼容矩阵补 TypeScript 行
- 顺手修 smoke.sh 的 npx 写法：npm 11 下 `npx -y typescript@X tsc` 必报 could not determine executable，须 `npx -y -p typescript@X tsc`（旧写法本地一直跑不通）
**验收状态**：`tsc --noEmit` 0 错；单测 4/4；`npm run build` exit 0（dist 8 文件、import 全为 `.js`）；dist 入口 import OK（exports: Config/apply/currentAgentId/dispose/inject/name）；`bash smoke.sh` 三步 SMOKE ALL GREEN（含真实 uvx 冷启动）
**待办（需老板/发布侧拍板，本批次未做）**：
- npm 上架的 0.1.0 是坏包 ⇒ 需 bump 0.1.1 + tag + dispatch publish 才会真正修好对外产物；发版动作未执行（凭据/发布决定权不在本线）
- dist/*.d.ts 的 import 仍写 `.ts`（TS 5.9 不改写声明文件）：消费者开 skipLibCheck 无感，否则类型解析会报 TS5097——留作小账
**下一步**：0.1.1 重发后复核 npm 包可 import；PR #94 跟进照旧

## 2026-09-16 · 0.1.1 预备：`.d.ts` 的 `.ts` 后缀收口 + dist 扩展门禁（`1c1d557` · `b0c633d`）
**做了什么**（老板令「0.1.1 一步到位，发版前把 .d.ts 的 .ts 后缀一并修掉」；**红线：禁 tag / 禁 dispatch / 禁 publish**）：
- 根因确认：TS 5.9.3 的 `rewriteRelativeImportExtensions` **只改写 JS emit，不碰声明文件** ⇒ 全清重建后 `dist/plugin.d.ts` 仍写 `from './config.ts'`（非陈旧产物）
- 修法（产物侧收口，`1c1d557`）：`scripts/fix-dts-ext.mjs` 构建后改写 `dist/**/*.d.ts` 相对 specifier `.ts|.tsx|.mts|.cts` → `.js|.js|.mjs|.cjs`，改完自检残留 exit 1；挂进 `npm run build`。源码侧不动——src 用 `.ts` 后缀是刻意的（`node --experimental-strip-types` 直跑 src 要靠它）
- 门禁：`scripts/assert-dist-ext.mjs` 扫 `dist/**/*.{js,d.ts}`，`.ts` 后缀即红。接 test job（**每次 push 都跑 = 杜绝复发主力**）＋ publish job dist 入口步（发布前再拦）。带阳性对照（注入 `.ts` 即 exit 1）确认非空跑
- CI 归一：publish job 由裸 `npx tsc -p tsconfig.build.json` 改走 `npm run build`（原先本地 `--noCheck` / CI 不带，两侧漂移）
- 版本位：`package.json` 0.1.0 → 0.1.1（`b0c633d`，仅版本号，**未打 tag / 未 dispatch**）；README×2 排障节补 TS5097 条
**验收状态**：`tsc --noEmit` 0 错；单测 4/4；`rm -rf dist && npm run build` exit 0（改写 2 处且自检通过）；`import('./dist/plugin.js')` DIST_OK；`assert-dist-ext` EXT_OK；`bash smoke.sh` 三步 SMOKE ALL GREEN（含真实 uvx 冷启动）；`npm pack --dry-run` 16 文件含 dist/\*.js+*.d.ts
**已知问题（性质更正）**：`dist/*.d.ts` 带 `.ts` 后缀**并非消费端功能缺陷**——TS 5.9.3 实测（NodeNext / Node16，`skipLibCheck=false`）消费端对修前修后**均 exit 0**（TS 会把 `./x.ts` 映射到同名 `x.d.ts`）；阳性对照＝`.ts` **源文件**引一个真实存在的 `.ts` 才报 TS5097。0.1.0 真正的对外断裂是 **JS emit**（`ERR_MODULE_NOT_FOUND`，`830d4bd` 已修）。故本条按老板令修掉＋加门禁，属「一步到位」的卫生收口，非修 bug —— 报老板/发版说明勿写成「0.1.0 类型层坏包」
